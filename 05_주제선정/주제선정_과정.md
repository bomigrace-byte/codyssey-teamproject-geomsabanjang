# 주제 선정 과정

7개 도메인에서 아이디어를 넓게 모은 뒤, 팀 투표와 기준 비교로 범위를 좁혀 최종 주제를 정했습니다.

```
14개 아이디어 (7개 도메인 × 2) → 팀 투표 → 도메인 확정 (AI Smart Factory)
→ 세부 후보 8개 비교 → 최종 주제: 불량 데이터가 부족한 현장의 AI 비전 품질검사
```

## 3단계. Smart Factory 세부 후보 8개 비교

| # | 후보 | 핵심 기술 | 검토 의견 |
|---|---|---|---|
| 1 | AI 설비 점검 보고서 자동 생성 | LLM | 기획은 쉽지만 "범용 LLM으로 충분하지 않나"라는 질문에 약하고, 손실 근거가 약함 |
| 2 | AI 설비 매뉴얼 검색 챗봇 | LLM, RAG | 1·7번과 구조가 겹치고 실제 매뉴얼 데이터 확보가 어려움 |
| **3** | **AI 비전 기반 제품 불량 검출** | **컴퓨터 비전, 이상 탐지** | **문제·기술·차별점이 한 줄로 연결되고 공개 데이터(MVTec AD)로 검증 가능** |
| 4 | AI 생산 일정 최적화 | 예측, 최적화 | 문제 설명과 기법 설명 부담이 커서 제외 |
| 5 | AI 설비 고장 예측 | 이상 탐지, 시계열 | 근거·데이터는 좋으나 차별화 여지가 상대적으로 작음 |
| 6 | AI 자재 재고·발주 추천 | 수요 예측 | 기존 ERP·자재소요계획(MRP)으로 대부분 해결되어 AI 필수성이 약함 |
| 7 | AI 신입 작업자 교육 도우미 | LLM, RAG | 1·2번과 구조가 겹침 |

## 4단계. 검토를 거친 보완

초안 완성 후 검토를 받아 과장될 수 있는 표현을 고쳤습니다.

| 수정 전 | 수정 후 |
|---|---|
| 불량 데이터 없이도 첫날부터 불량을 검출 | 정상 이미지로 모델을 구축하고 초기 검사를 시작하도록 지원, 실제 성능은 현장 검증 |
| 스마트폰으로 손쉽게 검사 | 조명·각도·배경을 고정한 촬영 환경을 전제로 한 초기 도입 방식 |
| 작업자 피드백으로 임계값 자동 보정 | 검증된 피드백으로 조정안을 제안하고 담당자가 승인 |
| AUROC 99.6% | 논문 벤치마크 수치이며 검출률이 아니고, 현장 성능은 별도 검증 |
| 기존 솔루션과 다른 기술 | 기술은 기존에도 있음, 차별점은 소기업을 위한 **도입 방식** |
